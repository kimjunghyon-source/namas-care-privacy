NAMAS-CARE 개인정보처리방침

최종 업데이트: 2026-08-28

NAMAS-CARE(CApture & REport, 이하 "확장")는 브라우저에서 발생한 오류·증상을 재현·전달하기 위한 화면 캡처/로그 수집 도구입니다. 이 문서는 확장이 어떤 데이터를 다루고, 어디에 저장하며, 어디로 전송되는지(또는 전송되지 않는지)를 설명합니다.

1. 서버로 전송되는 데이터: 없음

이 확장은 백엔드 서버가 없습니다. 모든 캡처 데이터는 사용자의 브라우저 안, IndexedDB(로컬 저장소)에만 저장되며, 확장 밖으로 전송되지 않습니다. 데이터를 꺼내려면 사용자가 직접 "내보내기" 버튼을 눌러 ZIP 또는 HTML 파일로 수동 다운로드해야 합니다 — 자동 업로드나 원격 동기화 기능은 없습니다.

2. 수집하는 데이터

사용자가 사이드패널에서 수집을 시작한 이후부터만 아래 데이터를 모읍니다(상시 수집 아님):

항목내용
화면 스냅샷클릭·오류 발생·페이지 전환 등 트리거 시점에 현재 탭을 캡처한 이미지(WebP). 화면에 보이는 텍스트·입력값·이미지가 그대로 담기며, 저장 전 아래 3항의 마스킹이 적용됩니다.
이벤트 로그클릭·스크롤·입력 등 사용자 조작 요약(좌표·대상 요소의 태그/역할 등). 입력창의 실제 입력값은 이 로그 자체에는 저장하지 않지만, 화면 스냅샷에는 찍힐 수 있습니다(그래서 3항의 마스킹이 스냅샷에 적용됩니다).
콘솔 로그페이지의 console.log/warn/error 출력, 처리되지 않은 JS 예외 및 Promise 거부.
네트워크 로그페이지가 발생시킨 요청의 URL·메서드·상태코드·헤더·(옵션 시) 응답 본문. 방문한 페이지의 URL·제목·시각도 함께 기록됩니다(방문 기록).
화면 녹화(선택)사용자가 명시적으로 켰을 때만 getDisplayMedia로 기록되는 영상(webm).

확장이 사용되는 환경(사내 그룹웨어·웹 메신저 등) 특성상, 위 데이터에는 다음과 같은 내용이 포함될 수 있습니다 — 브라우저 확장 스토어의 데이터 사용 공개 기준에 맞춰 명시합니다:

  • 개인 식별 정보: 이름, 주민등록번호, 전화번호, 이메일, 주소 등이 화면 텍스트나 입력값으로 찍힐 수 있습니다(스냅샷은 아래 3항 패턴에 따라 자동 마스킹).
  • 금융 및 결제 정보: 카드번호, 결제/거래 금액 등이 화면에 표시된 경우 스냅샷에 담길 수 있습니다(자동 마스킹 대상).
  • 인증 정보: 비밀번호 입력창은 항상 가려지지만, 로그인 화면 자체나 그 밖의 인증 관련 표시가 스냅샷·녹화에 담길 수 있습니다(화면 녹화는 마스킹 예외, 아래 참고).
  • 개인적인 커뮤니케이션: 사내 웹 메신저·채팅 등을 사용하는 화면을 캡처하는 경우 대화 내용이 스냅샷에 담길 수 있습니다.
  • 웹 기록: 위 네트워크 로그 항목대로 방문 페이지 URL·제목·시각이 기록됩니다.
  • 사용자 활동: 클릭·스크롤·마우스 위치·키 입력(비밀번호 제외) 등 조작 이벤트를 수집합니다 — 이 확장의 핵심 기능입니다.
  • 웹사이트 콘텐츠: 화면 스냅샷 자체가 페이지의 텍스트·이미지를 담습니다.

건강 정보와 위치 정보(GPS 등)는 이 확장이 목적으로 삼아 수집하지 않으며, 별도로 요청하는 브라우저 권한도 없습니다.

3. 개인정보 마스킹

화면 스냅샷에는 저장 전 자동 마스킹이 적용됩니다: 비밀번호 입력창은 항상 가려지고, 그 외 텍스트는 주민등록번호·전화번호·카드번호·이메일·생년월일 등 날짜·주소·금액·프로필 사진 패턴에 걸리는 부분을 자동으로 가립니다. 각 패턴 카테고리는 옵션 페이지에서 개별적으로 켜고 끌 수 있습니다.

예외: 화면 녹화(2항의 마지막 행)에는 마스킹이 적용되지 않습니다. 녹화를 켜면 화면에 보이는 그대로(개인정보 포함) 저장되며, 확장은 녹화 시작 시 이 점을 사용자에게 별도로 고지합니다. 자동 마스킹은 최선의 노력(best-effort) 방식으로, 완벽을 보장하지 않습니다 — 민감한 화면에서는 사용자가 직접 확인 후 편집기로 추가 마스킹하거나 내보내기 전 삭제할 것을 권장합니다.

4. 데이터 보관·삭제

  • 모든 데이터는 브라우저 로컬 저장소에만 남고, 7일이 지난 기록은 자동으로 삭제됩니다.
  • 사용자는 언제든 기록을 개별 선택해 즉시 삭제할 수 있습니다.
  • 확장을 제거하면 IndexedDB에 저장된 모든 데이터가 브라우저에 의해 함께 삭제됩니다.

5. 제3자 제공

이 확장은 어떤 제3자에게도 데이터를 제공·판매·공유하지 않습니다. 광고·분석·트래킹 SDK를 포함하지 않습니다.

6. 권한 사용 목적

확장이 요청하는 각 브라우저 권한이 실제로 어디에 쓰이는지는 별도 문서 (권한 정당화, permission-justification)에 항목별로 설명되어 있습니다.

English summary: NAMAS-CARE is a browser-troubleshooting capture tool with no backend server. All captured data (screenshots, console/network logs, optional screen recording) is stored only in the browser's local IndexedDB and never transmitted anywhere automatically; export is a manual, user-initiated file download. Screenshots are automatically masked for common PII patterns before being saved; screen recordings are explicitly NOT masked, and the extension warns users of this before recording starts. Records older than 7 days are auto-deleted. No data is shared with third parties.
